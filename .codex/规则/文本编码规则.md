# 文本编码规则

## 适用范围

本规则适用于《即时战略指挥》的客户端、服务器及其间的网络消息。

## 运行时文本

- 所有运行时 `std::string` 文本统一使用 UTF-8，包括账号、昵称、聊天内容、网络消息字段、配置读取结果、实体保存数据和跨进程/跨服务器消息。
- 字符串在函数参数、成员变量、容器、消息结构体和序列化数据之间传递时，必须保持 UTF-8 原样传递。
- 禁止为了赋值、转发、保存或网络传输而对运行时 UTF-8 文本调用 `StrConv::Utf8ToGbk`。
- 收到 UTF-8 文本后，直接赋值；例如：

  ```cpp
  .str账号 = responce.str账号,
  ```

  不要写成：

  ```cpp
  .str账号 = StrConv::Utf8ToGbk(responce.str账号),
  ```

## 源代码中文字符串常量

- C++ 源文件中的中文窄字符串字面量（如 `"登录成功"`、`"Key机甲"`）按 GBK 编码处理。
- 将这类中文字符串常量赋值、拼接或发送到 UTF-8 运行时文本字段前，必须调用 `StrConv::GbkToUtf8(...)`。
- 纯 ASCII 字符串不需要转换。

  ```cpp
  // 中文常量（GBK）转换为运行时 UTF-8。
  const std::string str提示 = StrConv::GbkToUtf8("登录成功");

  // ASCII 常量无需转换。
  const std::string str音效 = "BUZZ";
  ```

## GBK 转换的允许边界

- 仅在外部边界确实要求 GBK 时才调用 `StrConv::Utf8ToGbk(...)`，例如 Windows GBK 控制台日志输出。
- 日志输出后不得将 GBK 结果写回运行时成员变量、网络消息、配置对象或持久化对象。
- 若某个外部文件、第三方接口或旧系统要求 GBK，必须在调用点局部转换，并在附近注释说明该边界的 GBK 要求。

## 修改检查

- 新增或修改文本字段时，先确认该字段的运行时编码为 UTF-8。
- 发现 `Utf8ToGbk` 时，检查其结果是否只用于日志或明确的 GBK 外部接口；否则应删除该转换。
- 发现中文窄字符串常量进入运行时文本时，检查是否已先经过 `GbkToUtf8`。
